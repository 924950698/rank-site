常见问题

需要服务器吗？

不需要。渲染在你自己的电脑上跑（Chrome + ffmpeg），边际成本是零，所以不做云端排队。网页版要等以后再说。

字幕时间是怎么来的？

先对音轨做一次语音识别，把每个字的时刻摊出来；再拿你的稿子按文字相似度对上去，未匹配的字前后插值。对着真实配音实测，平均偏差 0.06 秒。

原片必须干净没字幕吗？

建议原片不带烧录字幕，否则会和新字幕叠在一起。画面字幕擦除是另一个功能，还没做。

能出哪些平台的比例？

横屏 16:9 和竖屏 9:16 两套。抖音、视频号、小红书走竖屏，B 站、YouTube 走横屏，同一个工程换预设就行。

卡片能自己加吗？

能。每张卡片就是一个 React 组件，带自己的节拍表，加进卡片库后在时间轴上按起止时间挂上去。
